# usvc-backend coding rules

1. **Cents on the server.** `priceOrder` only; browser `totalCents` recomputed and rejected on mismatch (422). Gov/shipping excluded (charged later). Paid orders never repriced; unpaid carts may reprice.
2. **Zod first.** Validate every request before use: `config/env.ts` (fail-closed env), `order-validation.ts` (`createOrderSchema`), `staffStatusUpdateSchema` (substatus only with `TO_CS` else 422), `validateCorrection()` → 422 `{message, errors}`. County→city checked against dataset; 9 CA counties blocked; identity format/plausibility/Luhn checks; phone E.164.
3. **Mongoose only.** Typed models + startup indexes. No raw driver, no second DB. Never make manual production data changes. Prefer atomic `$push`/`$set` updates for projection-loaded docs (claim/release/reassign/notes/correction); full-doc `save()` only after an unprojected `findById` (checkout-session, confirm, status, document flows use it).
4. **Webhooks done right.** `express.raw` body + `stripe.webhooks.constructEvent` verify; `StripeEvent.create({_id:event.id})` idempotency → `duplicate:true` short-circuit; `mongoose.startSession().withTransaction()` for order update + outbox upserts (`$setOnInsert` per-order keys) + audit `$push`. Handles `payment_intent.succeeded/failed`, `checkout.session.completed` (only if `payment_status==paid`), async success/fail. Browser redirect never trusted.
5. **Secrets never leak.** No plaintext customer PII, JWT/Stripe secrets, or decrypted values in logs, responses, audit metadata, emails, or projections. Internal order fields are never in public tracking/confirmation/summary projections (tested). Staff reads go only through authorized, audited endpoints. No stored short-form identifiers.
6. **Authz on every request.** `requireAuth` → `requireActiveStaff` → `requireAdmin` as needed (`requireActiveStaff` gates `/staff/*` + `/admin/*`; the `orders.ts` detail/audit/status/document routes are `requireAuth`-only today — see `status.md` backlog). Pricing + correction = ADMIN/CS only. CS must own an order to correct or mark `GTG` (ADMIN bypasses). Reassign/MFA-reset/revoke/staff-patch = ADMIN only. Last-ADMIN demote guard; self-change blocked. `PATCH /admin/staff/:id` accepts only `active|disabled` (never `pending|blocked`).
7. **Outbox discipline.** Resend/GA4/OpenAI deliveries go through leased, idempotent outbox collections (`$setOnInsert` per-order keys, provider idempotency keys). Staging uses `EMAIL_RECIPIENT_OVERRIDE`; production never does. Emails text-only branded headers (no `<img>`, tested).
8. **Env hygiene.** No real values in `.env.example` or docs. Fresh `SENSITIVE_ENCRYPTION_KEY` per environment; losing the prod key is unrecoverable — back it up offline.
9. **Gates.** `npm run build` + `npm test` (green — 18 files) before handoff; `format`, `format:check`, `lint`. Pre-commit: lint-staged + `tsc --noEmit` + `npm test`. TS gate is `tsc`.
10. **Git.** `feat/<name>` from `develop` → PR to `develop`. Never commit to `main`/`develop`.
