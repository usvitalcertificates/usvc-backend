# Public API (no staff token)

Base: `http://localhost:4000` locally. All amounts server-computed; browser never supplies an amount.

| Method | Path                                   | Notes                                                                                                                                                                                                                                                                        |
| ------ | -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GET    | `/health`                              | Health info.                                                                                                                                                                                                                                                                 |
| POST   | `/contact-messages`                    | `{fullName, email, orderNumber?, message, antiAbuse{honeypot, startedAt}}`. 5/IP/15min. SSN/card-like flagged, not blocked. No public read endpoint. Queues support notification + customer receipt.                                                                         |
| POST   | `/orders`                              | Full application create (unpaid). Per-cert subject/family, geo county/city, copies 1–20, consents + signature, display `totalCents` (recomputed; mismatch → 422). SSN/card encrypted to `confidentialData` before `Order.create`. Returns `{id, publicNumber, amountCents}`. |
| POST   | `/orders/verify-before-payment`        | Dry-run validation; returns canonical `amountCents`, no write.                                                                                                                                                                                                               |
| GET    | `/orders/geo/:stateCode?county=&city=` | County/city pair validation.                                                                                                                                                                                                                                                 |
| GET    | `/orders/checkout-config`              | Stripe publishable key (browser-safe).                                                                                                                                                                                                                                       |
| GET    | `/orders/:id/summary`                  | Whitelisted checkout summary (no SSN/card).                                                                                                                                                                                                                                  |
| POST   | `/orders/:id/checkout-session`         | Create/reuse Checkout Session (`ui_mode: elements`), server total, 3 line items. Rechecks blocked CA counties for unpaid orders.                                                                                                                                             |
| POST   | `/orders/checkout-session/confirm`     | Re-reads session from Stripe; marks paid.                                                                                                                                                                                                                                    |
| POST   | `/orders/tracking`                     | Public lookup by `{publicNumber, email}`. Returns customer-safe timeline only (Payment Successful → Received → Processing → Submitted; exceptions neutral).                                                                                                                  |
| POST   | `/webhooks/stripe`                     | Stripe-only (signature, not JWT). Idempotent by event ID; transaction queues one confirmation email + (if enabled) one GA4 purchase + one OpenAI `order_created` per order. Not a browser API.                                                                               |

## Contracts

- **Order create:** state slug/code/name, certificate, geo, reason, applicant, optional `requestorSsn`, per-cert subject/family, 3 addresses, destination type, copies, rush, delivery method, consents + payment authorization, signature, card details, display total. Birth requires valid SSN + subject suffix; Female recorded gender requires maiden last name; phone E.164; Visa/MC Luhn + 3-digit CVV.
- **Security:** card/SSN encrypted at creation; never logged/drafted/returned except once via staff reveal. Never send Stripe secrets to these routes. Tracking treats the public number as opaque.
