# Public API (no staff token)

Base: `http://localhost:4000` locally. All amounts server-computed; browser never supplies an amount.

| Method | Path                                   | Notes                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------ | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GET    | `/health`                              | Health info.                                                                                                                                                                                                                                                                                                                                                                                                                    |
| POST   | `/contact-messages`                    | `{fullName, email, orderNumber?, message, antiAbuse{honeypot, startedAt}}`. 5/IP/15min. Honeypot or implausibly-fast submit → 422; likely sensitive content flagged (not blocked). Stored + both emails queued in one Mongo transaction. No public read endpoint.                                                                                                                                                               |
| POST   | `/orders`                              | Full application create (unpaid). Per-cert subject/family, geo county/city, copies 1–20, consents + signature, display `totalCents` (recomputed; mismatch → 422). Paid-order OpenAI conversion always includes a SHA-256 email hash (no opt-in). Optional `analytics.openAiOppref/openAiObref` forward pixel cookies for CAPI matching. Returns `{id, publicNumber, amountCents, openAiEventId}` (shared pixel/CAPI dedup key). |
| POST   | `/orders/verify-before-payment`        | Dry-run validation; returns canonical `amountCents`, no write.                                                                                                                                                                                                                                                                                                                                                                  |
| GET    | `/orders/geo/:stateCode?county=&city=` | County/city pair validation.                                                                                                                                                                                                                                                                                                                                                                                                    |
| GET    | `/orders/checkout-config`              | Stripe publishable key (browser-safe).                                                                                                                                                                                                                                                                                                                                                                                          |
| GET    | `/orders/:id/summary`                  | Whitelisted checkout summary (public fields only).                                                                                                                                                                                                                                                                                                                                                                              |
| POST   | `/orders/:id/checkout-session`         | Create/reuse Checkout Session (`ui_mode: elements`), server total, 3 line items. Rechecks blocked CA counties for unpaid orders.                                                                                                                                                                                                                                                                                                |
| POST   | `/orders/checkout-session/confirm`     | Re-reads session from Stripe; marks paid.                                                                                                                                                                                                                                                                                                                                                                                       |
| POST   | `/orders/tracking`                     | Public lookup by `{publicNumber, email}`. 10/IP/15min. Returns customer-safe timeline only (Payment Successful → Received → Processing → Submitted; exceptions neutral).                                                                                                                                                                                                                                                        |
| POST   | `/webhooks/stripe`                     | Stripe-only (signature, not JWT). Idempotent by event ID; transaction queues one confirmation email + (if enabled) one GA4 purchase + one OpenAI `order_created` per order. Not a browser API.                                                                                                                                                                                                                                  |

## Contracts

- **Order create:** state slug/code/name, certificate, geo, reason, applicant, per-cert subject/family, 3 addresses, destination type, copies, rush, delivery method, consents + payment authorization, signature, display total. Validation rules enforced; see `order-validation.ts`. Female recorded gender requires maiden last name; phone E.164.
- **Security:** order fields never logged/drafted/returned except via authorized staff endpoints. Never send Stripe secrets to these routes. Tracking treats the public number as opaque.
